Gitflow

Ramas de Git Flow

  • main: contiene las versiones estables y listas para producción del proyecto.

  • develop: reúne los cambios de desarrollo que se incorporarán en futuras versiones.

  • feature: se utiliza para desarrollar nuevas funcionalidades de forma aislada, partiendo de develop. Una vez terminadas, se integran de nuevo en esta rama.

  • release: permite preparar una nueva versión, realizar pruebas y corregir errores antes de publicarla. Al finalizar, se integra en main y en develop.

  • hotfix: sirve para corregir errores críticos detectados en producción. Se crea desde main y, una vez resuelto el problema, los cambios se integran tanto en main como en develop.
